### Prev: expt_a300 (grid base)

Cell 319 (T1 mode 1 `fn`, mask 3) of the 2^4 x 3 workload-A ablation (`ablation/README.md`); every cell's factor levels are in `ablation/manifest.csv`. Generated by `ablation/generate.py` from `ablation/template/`: change the template and regenerate rather than editing this directory.

Everything not listed below is the grid's shared reference: the schema, distribution, indexes, T2, T3, T4, T8, T9 and server parameters of the workload-A base design (formerly `expt_a3`, see git history), with `expt_a323`'s run configuration (`--nodelist=xcnf[0-2,4,5]`, `TEAM_ID` default 4, `PGPORT` derived from `TEAM_ID`). `run.sh` also records plans outside the timed benchmark.

Enabled factors:

| Factor | Description |
| ------ | ----------- |
| `t5_routing` (bit 1) | T5 routing: T5 looks up `order_merchant_map`; T1 inserts the map row; `run.sh` creates, distributes, fills and truncates `order_merchant_map` |
| `t6_rollup` (bit 2) | T6 rollup: T6 reads `merchant_daily_sales`; T1 upserts the rollup row; `run.sh` creates it with `idx_mds_period`, distributes, fills and truncates it |
| `t1_mode=fn` (m=1) | T1 delegation: T1 is the `place_order` distributed function, called outside a transaction block; `run.sh` creates and distributes the function |

T1 is `expt_a323`'s, unchanged.
