### Prev: expt_a300 (grid base)

Cell 326 (T1 mode 1 `fn`, mask 10) of the 2^4 x 3 workload-A ablation (`ablation/README.md`); every cell's factor levels are in `ablation/manifest.csv`. Generated by `ablation/generate.py` from `ablation/template/`: change the template and regenerate rather than editing this directory.

Everything not listed below is the grid's shared reference: `expt_a100`'s (formerly `expt_a3`) schema, distribution, indexes, T2, T3, T4, T8, T9 and server parameters, with `expt_a9r`'s run configuration (`--nodelist=xcnf[0-2,4,5]`, `TEAM_ID` default 4, `PGPORT` derived from `TEAM_ID`). `run.sh` also records plans outside the timed benchmark.

Enabled factors:

| Factor | Description | Source |
| ------ | ----------- | ------ |
| `t6_rollup` (bit 2) | T6 rollup: T6 reads `merchant_daily_sales`; T1 upserts the rollup row; `run.sh` creates it with `idx_mds_period`, distributes, fills and truncates it | `expt_a102` (formerly `expt_a5`) |
| `shards8` (bit 8) | Eight shards: `run.sh` sets `citus.shard_count` to `CITUS_SHARD_COUNT` (default 8, Citus's own default is 32) in the session that distributes every table, and records it in `config.txt` | `expt_a331` (formerly `expt_a10`) |
| `t1_mode=fn` (m=1) | T1 delegation: T1 is the `place_order` distributed function, called outside a transaction block; `run.sh` creates and distributes the function | `expt_a111` (formerly `expt_a7`) |

T1's `place_order` is `expt_a111`'s with step 7 (`order_merchant_map` insert) removed from the function body. The signature, the pgbench-side statements and the rest of the body are unchanged, and the remaining steps keep the original numbering.
