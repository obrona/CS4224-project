### Prev: expt_a300 (grid base)

Cell 324 (T1 mode 1 `fn`, mask 8) of the 2^4 x 3 workload-A ablation (`ablation/README.md`); every cell's factor levels are in `ablation/manifest.csv`. Generated by `ablation/generate.py` from `ablation/template/`: change the template and regenerate rather than editing this directory.

Everything not listed below is the grid's shared reference: the schema, distribution, indexes, T2, T3, T4, T8, T9 and server parameters of the workload-A base design (formerly `expt_a3`, see git history), with `expt_a323`'s run configuration (`--nodelist=xcnf[0-2,4,5]`, `TEAM_ID` default 4, `PGPORT` derived from `TEAM_ID`). `run.sh` also records plans outside the timed benchmark.

Enabled factors:

| Factor | Description |
| ------ | ----------- |
| `shards8` (bit 8) | Eight shards: `run.sh` sets `citus.shard_count` to `CITUS_SHARD_COUNT` (default 8, Citus's own default is 32) in the session that distributes every table, and records it in `config.txt` |
| `t1_mode=fn` (m=1) | T1 delegation: T1 is the `place_order` distributed function, called outside a transaction block; `run.sh` creates and distributes the function |

T1's `place_order` is `expt_a323`'s with steps 6 (`merchant_daily_sales` upsert) and 7 (`order_merchant_map` insert) removed from the function body. The signature, the pgbench-side statements and the rest of the body are unchanged, and the remaining steps keep the original numbering.
Step 4 still has `RETURNING total_amount, created_at INTO v_order_total, v_created_at`, although only step 6 read them.
