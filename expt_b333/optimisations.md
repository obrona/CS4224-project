### Prev: expt_b300 (grid base)

Cell 333 (T1 mode 2 `fn_rr`, mask 1) of the 2^4 x 3 workload-B ablation (`ablation/README.md`, "Workload B"); every cell's factor levels are in `ablation/manifest_b.csv`. Generated by `ablation/generate.py --side b` from `ablation/template/`: change the template and regenerate rather than editing this directory.

`transactions/` and `explain/` are byte-identical to `expt_a333`'s, the workload-A cell with the same factor levels, and `run.sh` differs from `expt_a333`'s only in the node pin (`--nodelist=xcnf[17-21]`, the B-side node set: disjoint from A's and shared by every B cell), the mail user and the `WORKLOAD` default (`B`).

Everything not listed below is therefore the grid's shared reference, as on workload A: the schema, distribution, indexes, T2, T3, T4, T8, T9 and server parameters of the workload-A base design (formerly `expt_a3`, see git history), `TEAM_ID` default 4 and `PGPORT` derived from `TEAM_ID`. `run.sh` also records plans outside the timed benchmark.

Enabled factors:

| Factor | Description |
| ------ | ----------- |
| `t5_routing` (bit 1) | T5 routing: T5 looks up `order_merchant_map`; T1 inserts the map row; `run.sh` creates, distributes, fills and truncates `order_merchant_map` |
| `t1_mode=fn_rr` (m=2) | T1 delegation under REPEATABLE READ: as `fn`, plus `PG_ISOLATION_LEVEL` defaults to `repeatable read` instead of `serializable` |

T1's `place_order` is `expt_a323`'s with step 6 (`merchant_daily_sales` upsert) removed from the function body. The signature, the pgbench-side statements and the rest of the body are unchanged, and the remaining steps keep the original numbering.
Step 4 still has `RETURNING total_amount, created_at INTO v_order_total, v_created_at`, although only step 6 read them.

The code is cell 317's (T1 mode `fn`, the same mask) except for one line of `run.sh`: `PG_ISOLATION_LEVEL` defaults to `repeatable read` instead of `serializable`. `run.sh` writes it to every node's `default_transaction_isolation`, so it applies to every transaction of the workload, not only T1.
