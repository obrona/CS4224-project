### Prev: expt_b100 (base)

Cell 0 of the 2^5 workload-B ablation (`ablation/README.md`); every cell's factor levels are in `ablation/manifest_b.csv`. Generated by `ablation/generate.py --side b` from `ablation/template/`: change the template and regenerate rather than editing this directory.

Every cell of the workload-B ablation is generated; none is a renamed earlier experiment. `expt_b100` is `expt_b3`'s code on the A-ablation template. `transactions/` and `explain/` are byte-identical to `expt_a100`'s, the workload-A cell with the same mask; `run.sh` differs from it only in the node pin (`xcnf[17-21]`), the mail user and the `TEAM_ID` and `WORKLOAD` defaults.

Everything not listed below is exactly `expt_b100`'s: schema, distribution, indexes, T2, T3, T4, T8, T9 and server parameters. `run.sh` also records plans outside the timed benchmark, as `expt_a115` does.
